# ShinAI 旧サイト（役目を終えたリポジトリ）

シンアイ株式会社のウェブサイトは、独自ドメインへ移転しました。

- 現行サイト: https://shinai-inc.jp/
- 現行リポジトリ: `shin-ai-inc/website-v2`

このリポジトリ（`gh-pages` ブランチ）が配信しているのは、旧URLから
現行サイトへ案内するための移転ページのみです。

## ここに置くもの・置かないもの

`shin-ai-inc.github.io/website/` 配下には robots.txt が効きません。
GitHub Pages のプロジェクトページでは、robots.txt はドメイン直下
（`shin-ai-inc.github.io/robots.txt`）のみが参照され、そこは別リポジトリの管轄です。

つまり、このリポジトリに置いたファイルはすべて公開・巡回対象になり、
クロールを拒否する手段がありません。移転ページに必要なファイル以外は置かないこと。

かつて存在した旧サイトの本文・APIコード・設計文書は、この方針に基づき削除しました。
内容が必要な場合は Git の履歴から参照できます。
